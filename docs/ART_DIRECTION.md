# 修仙台 · 修士档案美术资源计划

## 视觉基线

- 固定主角：白发、白衣、中性偏清冷的年轻修士。
- 画面语言：水墨线稿、低饱和淡彩、宣纸肌理、黛青与米白为底，朱砂和鎏金做重点。
- 参考方向：角色档案、功行卷宗、古籍面板；保持信息可读性，不把应用改成战斗界面。

## 资源目录

| 目录 | 资源 | 当前用途 |
| --- | --- | --- |
| `art/portraits` | 半身立绘、头像裁切 | 首页修士档案、静室、功法页 |
| `art/icons` | 丹药、丹炉、飞剑、灵石、玉佩、符箓、灵根 | 法器栏、功法、境界和状态 |
| `art/ui` | 卷轴面板、按钮、边框、进度条、弹窗 | 关键页面的局部换肤 |
| `art/backgrounds` | 远景云海、中景山峦、洞府和纸纹 | 页面背景与轻微漂移层 |
| `art/fx` | 灵气、香火、经脉、雷劫序列帧 | 已有状态反馈和渡劫结算 |
| `art/tiles` | 山石、树木、草地、水面、道路、建筑组件 | 预留给未来地图或洞府场景，不影响当前功能 |

## 保留的现有交互

- 任务完成时的“毕”字朱印落印动效。
- 香炉烟气、燃香状态和入定计时。
- 经脉点亮、修炼完成浮字和渡劫结算。
- 现有数据统计、日志、功法和修炼记录功能。

## 实施顺序

1. 主角档案、头像裁切和卷宗式首页。
2. 功法、境界、体魄、经脉和法器图标。
3. 面板、按钮、边框和进度条的局部换肤。
4. 山水背景和纸张层。
5. 灵气、香火、雷劫等反馈特效。
6. 地图瓦片和场景组件作为独立资源包保留。

资源采用可替换文件名，后续新增素材只需覆盖对应资源或更新引用，不改后端接口。
